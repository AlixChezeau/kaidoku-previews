# kaidoku-previews

Previews temporaires des visuels Kaidoku (illustrations AI générées pour les PR drafts en attente de validation).

Auto-nettoyage : les dossiers sont supprimés après merge du PR correspondant sur le repo principal `kaidoku` (privé).

Ce repo est public uniquement pour permettre à `raw.githubusercontent.com` de servir les previews dans les PR comments (les URLs raw ne sont accessibles que pour les repos publics).

Ne contient rien d'éditorial, juste des PNG éphémères.
